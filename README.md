# سَنَد AI — استوديو ذكاء اصطناعي محلي بهوية سعودية

تطبيق آيفون يشغّل نماذج اللغة **على الجهاز بالكامل** (llama.cpp + Metal)، مع **نظام وكلاء** ينفّذ المهام خطوة بخطوة بالأدوات، وأدوات سعودية مدمجة.

## المميزات
- **محادثة محلية** ببث مباشر، سرعة الرموز/ث، شخصيات (فصحى، نجدي، حجازي، معلّم، مرشد أنظمة، مبرمج)، مشاركة وتصدير.
- **نظام الوكلاء (Agent)**: حلقة تخطيط ← استدعاء أداة ← قراءة النتيجة ← إجابة، مع عرض مسار كل خطوة، وطلب موافقتك قبل أي إجراء يكتب على جهازك. وكلاء جاهزون (شامل، باحث مستندات، مستشار مالي، منظّم مهام، مبرمج) ومحرر لصنع وكيلك.
- **الأدوات**: حاسبة عشرية دقيقة، التاريخ الهجري (أم القرى)، مواقيت الصلاة لـ18 مدينة، القبلة، الزكاة، ضريبة 15%، مكافأة نهاية الخدمة، البحث في المستندات، الملاحظات، التذكيرات والتقويم (EventKit)، نص الصورة، وبحث ويب اختياري (معطّل افتراضياً).
- **مكتبة النماذج**: ALLaM 7B (سدايا)، Qwen3 1.7B/4B، Gemma 3، Llama 3.2، Qwen2.5 — تحميل مع استئناف، فحص الذاكرة، واستيراد GGUF من الملفات.
- **العدسة**: OCR عربي/إنجليزي على الجهاز ← اشرح / ترجم / لخّص / حل / راجع الكود.
- **قاعدة المعرفة**: PDF/TXT/MD مع بحث BM25 عربي محسّن.
- **الصوت**: إملاء صوتي عربي على الجهاز وقراءة الردود.
- **خادم API محلي** متوافق OpenAI و Ollama مع مفتاح Bearer في Keychain.
- **الخصوصية**: بدون حساب وبدون تحليلات، و"مسح كل البيانات".

## البناء (GitHub Actions)
كل push على فرع `sanad-ai` يشغّل `.github/workflows/build.yml`:
1. ينزّل `llama.xcframework` الرسمي (`b11960`).
2. يولّد المشروع بـ XcodeGen ويشغّل اختبارات الوحدة على المحاكي.
3. يلتقط لقطات شاشة لكل تبويب.
4. يبني **IPA غير موقّع** ويرفعه في Releases باسم `sanad-build-N`.

محلياً على ماك:
```bash
./scripts/fetch-llama.sh && xcodegen generate && open SanadAI.xcodeproj
```

## التثبيت عبر ESign
1. حمّل `SanadAI.ipa` من صفحة Releases.
2. افتح ESign ← استورد الملف ← وقّع بشهادتك ← ثبّت.
3. للنماذج الكبيرة (ALLaM 7B / Qwen3 4B) فعّل في ESign صلاحية `com.apple.developer.kernel.increased-memory-limit` إن كانت شهادتك تدعمها.
4. افتح التطبيق ← النماذج ← اكتشف ← حمّل **Qwen3 1.7B** ← تشغيل.

## النشر على App Store
يتطلب حساب Apple Developer وشهادة توزيع وملف Provisioning وتطبيقاً في App Store Connect بالمعرّف `com.moha700m.sanadai`. بعدها يُضاف workflow توقيع ورفع (fastlane) يقرأ الأسرار من GitHub Secrets.

## الاختبارات
منطق `App/Core` مستقل عن UIKit ويُختبر في `Tests/CoreTests.swift` (38 اختباراً: الوكيل، الهجري، الصلاة، الزكاة، الضريبة، الحاسبة، BM25، تحليل استدعاءات الأدوات، خادم HTTP).
