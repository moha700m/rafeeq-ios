# رفيق · Rafeeq
Habit-building virtual pet (falcon, camel, cat) for Saudi users. SwiftUI, iOS 17+, Liquid Glass on iOS 26.

- Remote content: `docs/catalog.json` (served via GitHub Pages) — edit to change habits, trips, events, shop prices and pet lines without an app update.
- Firebase (social sync): rules in `firebase/`. Not yet connected.
- CI: `tests.yml`, `release.yml` (TestFlight), `screenshots.yml`.
